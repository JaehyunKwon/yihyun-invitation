# 👶 딸의 첫 번째 생일 파티 모바일 초대장 💕

딸의 돌잔치를 위한 커스텀 모바일 웹 초대장입니다.  
파스텔 핑크와 골드 톤앤매너, 위치 안내 지도 및 성장 영상 감상 기능 등을 제공합니다.

---

## 🎨 주요 기능 및 특징

* **감성적인 디자인:** 따뜻한 파스텔 핑크와 금빛 반짝이 배경 연출
* **아기 포토 프레임:** 금빛 타원형 프레임에 담긴 아기 한복 프로필 사진
* **위치 및 교통 안내:** 
  * 구글 지도 `iframe`을 통한 행사 장소(경복궁 건대점) 위치 바로보기
  * 네이버 지도 및 카카오맵 길찾기 바로가기 버튼 제공
  * 지하철 상세 대중교통 안내 카드
* **성장 영상 섹션:** 독립된 전용 카드 프레임 내 비디오 재생 기능
* **모바일 최적화:** 모바일 화면 크기에 맞춰 가독성 높게 반응하는 퍼스트 레이아웃

---

## 🛠️ 사용 기술 (Tech Stack)

* **HTML5**
* **CSS3** (Flexbox, CSS Variables, Responsive Design)
* **Google Fonts** (Gaegu, Gowun Batang, Noto Sans KR)
* **GitHub Pages** (웹 호스팅)
