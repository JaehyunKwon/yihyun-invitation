# 👶 이현이의 첫 번째 생일 파티 모바일 초대장 💕

가족들에게 전달하기 위한 커스텀 모바일 웹 초대장을 만들었습니다.  
아기자기한 감성의 디자인과 위치 안내, 아기 영상 감상 기능 등을 제공합니다.

---

## 🎨 주요 기능 및 특징

* **감성적인 디자인:** 따뜻한 파스텔 핑크와 골드 톤앤매너, 반짝이 배경 연출
* **아기 액자 프레임:** 금빛 타원형 포토 프레임에 담긴 아기 한복 사진
* **위치 및 교통 안내:** 행사 장소(경복궁) 안내 및 네이버/카카오 지도 연결 버튼 제공
* **성장 영상 섹션:** 독립된 전용 카드 프레임 내 커스텀 플레이 버튼을 통한 영상 감상 기능
* **모바일 최적화:** 모든 스마트폰 화면 크기에 맞춰 가독성 높게 반응하는 모바일 퍼스트 레이아웃

---

## 🛠️ 사용 기술 (Tech Stack)

* **HTML5**
* **CSS3** (Flexbox, CSS Variables, CSS Animations)
* **JavaScript** (Vanilla JS - 비디오 플레이어 제어)
* **Google Fonts** (Gaegu, Gowun Batang, Noto Sans KR)
* **GitHub Pages** (웹 호스팅)
